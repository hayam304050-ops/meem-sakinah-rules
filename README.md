# meem-sakinah-rules
الميم االساكنة لها ثلاثة احكام 
الادغام الاظهارالشفوى الاخفاء الشفوى 
اولا الادغام مثال يعلم ما وهم مهتدون 
ثانيا الاخفاء الشفوى يعتصم بالله هم بارزون
ثالثا الاظهار الشفوى هم فيها عليكم انفسكم 
اسىلة ما الحكم التجويدى فى هذه الكلمات 
هم فيها ---انهم هم---هم خير ---ربهم من ---هم عنها ---كنتم بها ---وخلقنكم ازواجا ---واهجرهم هجرا
